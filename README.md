# Fashion Store

Multi-platform Flutter shopping app (WIP) with Firebase integration.

Status: Active development — Phase files available (PHASE1..PHASE4).

## Summary

This repository contains a Flutter-based shopping app focused on fashion products. It's scaffolded for Android, iOS, web, and desktop, and integrates with Firebase for backend services (auth, firestore, etc.).

## Tech Stack

- Firebase (Auth, Firestore, others)

## Quick Start

Prerequisites:

- Install Flutter (stable) and platform toolchains (Android SDK, Xcode for iOS if needed)
- (Optional) Firebase CLI for configuring projects

Commands:

```bash
flutter pub get
flutter run             # runs on connected device or emulator
flutter test            # run unit tests
flutter build apk       # build Android APK
flutter build web       # build web app
```

Notes:

- This project includes `lib/firebase_options.dart` generated by Firebase tooling. If you replace Firebase projects, re-run the FlutterFire configuration and update platform config files.
- Android config file present at `android/app/google-services.json`; iOS requires `GoogleService-Info.plist` to be added under `ios/Runner` when using iOS.

## Android Google Sign-In

For Google sign-in to work from a USB-installed APK or a shared test APK, the Firebase Android app must include the SHA fingerprints for the certificate used to sign that APK. These debug/test fingerprints are already registered for the `c2b-shopping-app` Firebase Android app.

Current Android package name:

```text
com.example.fashion_store
```

Current debug/test APK signing fingerprints:

```text
SHA-1:   2D:BC:FD:25:62:07:6E:EA:24:B7:BE:BD:62:56:67:ED:52:04:47:B9
SHA-256: 01:10:5D:F2:B0:72:6E:C6:6D:16:CD:01:5D:1A:1D:69:4C:F9:5E:2C:4B:8E:EA:9F:0F:3C:34:19:B1:FC:4F:00
```

After changing the signing key, add the new SHA fingerprints in Firebase Console > Project settings > Your apps > Android app, then download the refreshed `google-services.json` and replace `android/app/google-services.json`. The refreshed file should contain an Android OAuth client (`client_type: 1`) for this package.

Also confirm Firebase Console > Authentication > Sign-in method has Google enabled. If the Google Cloud OAuth consent screen is in testing mode, publish it or add the client's Google accounts as test users before sending the APK.
